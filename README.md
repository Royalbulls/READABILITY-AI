# ✨ Overview

Readability AI is an intelligent web application that transforms difficult, lengthy, or technical text into clear, natural, and reader-friendly content using Google's Gemini AI.

Whether you're a student, professional, writer, marketer, educator, or business owner, Readability AI helps improve readability while preserving the original meaning.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/Royalbulls/READABILITY-AI.git
```

```bash
cd READABILITY-AI
```

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment

Create a file named:

```text
.env.local
```

Add:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

---

## Start Development Server

```bash
npm run dev
```

---

## Production Build

```bash
npm run build
```

---

## Preview Build

```bash
npm run preview
```
