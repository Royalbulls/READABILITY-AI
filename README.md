# 📖 About

READABILITY-AI is an AI-powered platform designed to simplify technical, legal, medical, academic, and business documents into easy-to-understand language.

Beyond simplification, it provides:

- 📚 AI Academy
- 💼 Business Studio
- 📊 Project Report Generator
- 🎓 Learning Platform
- 🚀 Creator Economy
- 🛒 Marketplace
- 🤖 AI Knowledge Search

# 🚀 Getting Started

## Install

```bash
npm install
```

## Environment

Create

```
.env.local
```

Add

```
GEMINI_API_KEY=YOUR_API_KEY
```

## Run

```bash
npm run dev
```
